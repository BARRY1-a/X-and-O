# x and o

A small, responsive Tic Tac Toe game that runs in any modern web browser.

## Play

Open `index.html` in your browser. Choose **2 players** for a local match or **vs computer** to play against the computer. The computer uses a strategy that never loses. The scoreboard tracks X wins, O wins, and draws, and is saved in your browser between visits.

Use **New round** to replay without changing the scores, or **Reset scores** to clear the scoreboard.

## Files

- `index.html` — game structure and controls
- `style.css` — responsive styling
- `script.js` — game rules, computer opponent, and persistent scores
